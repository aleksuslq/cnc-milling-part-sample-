# cnc-milling-part-sample
CNC G-code for Manifold Machining
This repository contains the G-code (.NC) generated in SOLIDWORKS CAM 2023 for CNC machining of a manifold.
The project includes:
3-axis CNC toolpaths
Post-processed G-code for milling operations
Tool changes, spindle speeds, and feed rates
Machining sequence for the manifold model
Software: SOLIDWORKS CAM 2023
File type: .NC (G-code)
